# Task description

Generate a README.md file for documentation.

Look for the code to be documented in the folders code, src.

Search and analyze the files that correspond to some programming language.

Analyze all the files you consider necessary to make the documentation as complete as possible.

Reviews the generated README.md file for validity and completeness.

The project metadata is located in the file application.yml

## Instructions to organize the README.md file:

1. Create a project Title
2. Add a project description, based on the project code
3. Add a Table of contents
4. Add a section of used tecnologies
5. Add a section of requirements
6. Add a section with the basic Installation Instructions.
   - Add code snipets
7. Add a section of Usage Instructions
8. Add a section of documentaion or a link to a documentation folder if exists
9. Add a section of Suport information
   - search files with metadata to supplement support information
