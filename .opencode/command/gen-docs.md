# Task description

Generate a group of documentation files in markdown inside de docs folder.

Look for the code to be documented in the folders code, src.

Search and analyze the files that correspond to some programming language.

Generate all the files you think necessary to make the documentation as complete as possible.

Reviews the generated documentation for validity and completeness.

## Instructions to organize the documentation files:

1. Create a Index.md file
   - This file needs a navigation index of all the documentaion.
2. Each file needs a proper index
3. Separate the documentation in logic folders

## Instructions to generate each file of documentation:

1. Check is exist the documentation files in the project
2. If exist read and complete the documentation
3. If not exist, create a new file with a resume and links of the documentation.
4. Group all the files and links based on the folder strcuture
5. For each file
   - Create a new file with a number and a descriptive name
   - This new file should contain a summary of the code file, a list of the available functions and methods and if necessary an example of use.

## Instructions validate the documentaion:

1. Read de generated files.
2. Search and validate the content of de documentation file with the correspondign code file.
3. Edit de documentaion file with the correct changes.
